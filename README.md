# VITRANO — Твій світ покупок

Окремий україномовний онлайн-магазин. Проєкт не пов'язаний із MarketMix UA, Universal Marketplace UA або NORD.

## Ресурси
- GitHub: https://github.com/karinavurvihvost-max/vitrano
- Render: https://vitrano-storefront.onrender.com
- Render dashboard: https://dashboard.render.com/static/srv-dbcuj1qfngtc73b2v5s0

## Стан на зараз
- Адаптивна стартова вітрина, пошук, фільтри, картки товарів і UI кошика.
- Чернетка структури бази даних у `database/schema.sql`.
- Репозиторій поки публічний, як вирішив власник.
- Окремий платний проєкт Supabase поки не створювали. Схему SQL не застосовано.
- Оформлення замовлення та адмін-панель не підключені; магазин поки не готовий приймати реальні замовлення.

## Наступні етапи
1. Після рішення власника створити окремий Supabase-проєкт VITRANO та погодити вартість.
2. Застосувати й перевірити схему, RLS і ролі адміністратора.
3. Підключити каталог та захищене сховище фотографій.
4. Реалізувати серверне оформлення замовлення з повторною перевіркою цін, наявності та одного постачальника на замовлення.
5. Створити захищену адмін-панель для товарів, постачальників, замовлень, ТТН, відгуків і фінансів.
6. Перевірити на телефоні та пройти тестові сценарії перед запуском.

## Безпека
Не зберігати секретні ключі в публічному репозиторії. Не передавати в браузер Supabase service-role/secret key. Всі таблиці, доступні через API, повинні мати RLS та перевірені політики. Замовлення повинні створюватися серверною функцією з валідацією та захистом від спаму.
